- 完成 UI/前端设计规范：`design-system.md`（适配小学/初中考试培训系统）。
- 完成偏好沉淀：`user.md`（路径、技术栈、文档版本化规则、执行规则）。
- 完成新版架构文档升级：`architecture-v1.12.md`（补充平台架构图）。
- **新增** 完整业务流程梳理（v1.5需求文档核心更新）：
  - 管理员业务流程（赛前准备/赛中监控/赛后处理）
  - 指导老师业务流程（日常教学/组卷管理）
  - 学生（训练账号）业务流程（激活/训练/错题/资源）
  - 学生（考试账号）业务流程（考试进行/赛后查询）
  - 评卷老师业务流程（评卷/复查）
- **关键业务规则确认**：
  - 账号学段关联：训练账号、考试账号、教师账号均关联学段（小学/初中）
  - 组卷分工：管理员组考试卷；指导老师组练习卷
  - 考试卷绑定：1卷1场次，不允许多场次共用
  - 主观题作答：按卷配置二选一（上传附件/在线富文本）
  - 激活码周期：支持快捷配置（3个月/半年/1年）或自定义起止日期，支持重新激活
  - 练习卷可见范围：指导老师组的卷仅自己所带的训练账号可见
  - 历年真题卷：由考试卷转换，继承原学段，同学段训练账号可见
  - 评卷分配：考试全部结束后统一分配（随机+工作量均衡）
  - 成绩公布：含主观题场次设时间到期自动公布，纯客观题场次考前配置
  - 复查规则：公布后48小时内可申请，每场限1次，回避原则分配复查老师
  - 考试时间轴：起始时间+时间长度（快捷/自定义）自动算结束时间
  - 学段匹配：所有核心资源（账号/试卷/场次）均需学段匹配
