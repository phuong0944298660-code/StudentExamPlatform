# Exam System Design System

## 1. 文档信息

- 文档名称：考试与培训系统设计规范
- 文档版本：v1.0
- 生效范围：`C:\Apps\TraeOwnProject\examSystem` 全部前端与 UI 设计产物
- 适用对象：产品、UI 设计、前端开发、测试
- 生效日期：2026-03-26

## 2. 执行原则（强制）

- 后续所有 UI 设计与前端开发必须遵循本规范。
- 若业务需求与本规范冲突，先在需求文档中标注冲突点，再更新本规范版本后实施。
- 不允许页面“各做各的样式”，所有颜色、间距、组件状态必须使用本规范定义的设计令牌（Design Tokens）。

## 3. 设计目标与人群定位

本系统服务小学、初中考试与培训场景，视觉和交互目标如下：

- 清晰可靠：信息优先级明确，降低考试操作风险。
- 友好克制：适合中小学生，不幼稚、不娱乐化过度。
- 稳定高效：后台管理与评卷以效率为先，减少误操作。
- 一致可学：同类操作在所有页面行为一致，降低学习成本。

## 4. 前端框架与基础技术规范

## 4.1 推荐技术栈（前端）

- 框架：`Vue 3 + TypeScript`
- UI 组件：`Element Plus`（统一二次主题）
- 状态管理：`Pinia`
- 路由：`Vue Router`
- 图表：`ECharts`
- 富文本/附件预览：统一组件封装，不得每页重复造轮子

## 4.2 样式工程规范

- 统一使用 CSS 变量承载颜色、字号、圆角、阴影、间距。
- 业务页面禁止写硬编码颜色值（如 `#409eff` 直接写在页面内）。
- 组件样式扩展优先使用主题变量与语义类，不使用深层级覆盖。

## 5. 视觉系统

## 5.1 色彩体系（主色与语义色）

- 主品牌色（Primary）：`#1F6FEB`（可信、教育、科技感）
- 主品牌悬停：`#1558C0`
- 主品牌浅底：`#EAF2FF`
- 辅助色（Secondary）：`#00A870`（通过、成功、完成）
- 强提醒色（Warning）：`#F59F00`
- 错误色（Danger）：`#E03131`
- 信息色（Info）：`#0EA5E9`

中性色：

- 文字主色：`#1F2937`
- 次级文字：`#4B5563`
- 辅助文字：`#6B7280`
- 边框：`#D1D5DB`
- 分割线：`#E5E7EB`
- 页面背景：`#F5F7FB`
- 卡片背景：`#FFFFFF`

可访问性要求：

- 正文文字与背景对比度不低于 `4.5:1`
- 仅靠颜色表达状态时，必须配合图标/文案标签

## 5.2 学段主题（小学/初中）

- 小学主题：在不改变主品牌色前提下，允许提高亮度和圆角（更亲和）。
- 初中主题：降低装饰性，增加信息密度（更稳重）。
- 学段主题只允许改变“装饰层”，不可改变核心语义色含义。

## 5.3 字体与排版

- 字体族：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 标题字重：`600`
- 正文字重：`400`
- 数字与指标建议使用等宽数字特性（便于比对）

字号层级：

- 页面主标题：24
- 区块标题：18
- 卡片标题：16
- 正文：14
- 辅助说明：12

## 5.4 间距、圆角、阴影

- 基础间距单位：`8px`
- 常用间距：`8/12/16/20/24/32`
- 卡片圆角：`12px`
- 输入框/按钮圆角：`8px`
- 默认阴影：`0 4px 12px rgba(15, 23, 42, 0.08)`

## 6. 布局规范

## 6.1 通用布局

- 采用 `12` 栅格系统。
- 页面结构：顶部导航 + 左侧菜单 + 内容区（后台端）。
- 内容区宽屏最大宽度建议：`1440px`，超宽居中。

## 6.2 首页看板布局

- 顶部放关键指标豆腐块（首屏可见）。
- 第二层放趋势图与状态分布。
- 第三层放待办与风险告警。
- 每个豆腐块信息层级：指标名 > 当前值 > 辅助口径/变化值。

## 7. 组件规范

## 7.1 豆腐块（Metric Card）

- 结构：标题、主值、副值、右上角口径图标 `!`。
- 强制要求：每个豆腐块右上角必须有 `!` 图标。
- 交互：
  - PC：悬停显示口径定义 Tooltip
  - 触屏：点击图标显示口径定义 Popover
- 示例（平台管理员）：`今日预计考试人数 / 当前考试登录人数`

## 7.2 表单组件

- 必填项使用统一标识 `*`，错误提示在字段下方就近展示。
- 提交按钮与取消按钮间距固定，避免误点。
- 批量导入必须有：模板下载、导入预校验、错误行导出。

## 7.3 表格组件

- 表头吸顶（数据量大时必须支持）。
- 支持列显隐与固定列（左侧关键身份列固定）。
- 超长文本省略，悬停显示完整内容。

## 7.4 状态标签

- 未开始：灰色
- 进行中：蓝色
- 已完成：绿色
- 异常/失败：红色
- 状态文案与色彩保持全系统一致

## 7.5 视频播放器（资源中心）

- 必须支持：
  - 倍速播放（至少 `0.75x / 1.0x / 1.25x / 1.5x / 2.0x`）
  - 键盘左右键快进/快退 `5s`
  - 普通窗口与全屏播放切换
- 播放控件在 3 秒无操作后自动弱化显示，鼠标移动恢复。

## 7.6 附件上传组件（考试主观题）

- 支持类型：图片、文档、压缩包。
- 上传后支持预览、替换重传、删除重传。
- 明确显示上传状态：上传中/成功/失败。
- 上传完成即标记该题“已填写”，并触发实时保存。

## 8. 交互规则

## 8.1 通用交互

- 所有可点击区域最小 `40x40px`。
- 关键操作需二次确认：交卷、批量删除、场次开关关闭。
- 操作反馈统一 3 态：处理中、成功、失败。

## 8.2 考试场景交互

- 考试页面默认“专注模式”，弱化非必要导航。
- 左侧答题卡展示已答/未答状态，支持跳题。
- 自动保存状态必须可见（如“已保存于 14:21:32”）。
- 无答案解析展示，仅支持答题与上传。
- 交卷前弹窗二次确认，并展示未完成题目数量。

## 8.3 成绩可见规则

- 结果可见条件：`评分完成` 且 `成绩发布开关=开`。
- 若条件不满足，显示“考试结果尚未公布”状态页。
- 若条件满足，展示总分与各大题型总得分，不展示逐题分值（简化版）。

## 9. 按角色首页看板规范

## 9.1 平台管理员首页

- 核心豆腐块：`今日预计考试人数 / 当前考试登录人数`
- 场次状态：待开启、进行中、已结束
- 评分进度：未评、评卷中、已评
- 成绩同步：成功数、失败数
- 系统告警：登录异常、上传失败、保存失败、接口超时

## 9.2 赛事管理员首页

- 场次实时开放状态与开/关控制入口
- 已登录考生（口径：考试账号登录账户数）
- 评分完成率与出分时间
- 查询开关状态与待处理质疑

## 9.3 评卷老师首页

- 我的任务：未评、评卷中、已评
- 快速继续评卷入口
- 评分规则提示（算法、人数要求）
- 超时任务提醒

## 9.4 教师首页

- 练习进度与班级表现
- 错题与知识点分布
- 资源更新与热门内容
- 题库编辑与组卷快捷入口

## 9.5 学生首页（含原家长查看场景）

- 考后结果状态：已发布/未发布
- 已发布：展示总分、各大题型总得分、提交时间
- 未发布：统一展示“结果尚未公布”

## 10. 响应式与终端适配

- 断点建议：
  - `>=1200`：桌面端
  - `768-1199`：平板端
  - `<768`：移动端
- 移动端策略：
  - 看板卡片单列堆叠
  - Tooltip 改为点击 Popover
  - 考试页面保留核心路径，非关键信息折叠

## 11. 动效规范

- 动效时长：`150ms-250ms`
- 用途：页面切换、卡片加载、状态反馈
- 禁止过度动画，考试态只保留必要反馈动效

## 12. 可用性与无障碍

- 支持键盘 Tab 顺序访问核心流程。
- 关键按钮、输入框、错误提示可被屏幕阅读器识别。
- 图标按钮必须有文本替代说明（含口径图标 `!`）。

## 13. 设计交付与前端落地

- UI 交付需包含：页面稿、组件规范、状态稿（空/错/加载）、口径文案。
- 前端落地需建立统一组件：
  - `MetricCard`
  - `DefinitionTooltip`
  - `ExamAnswerCard`
  - `UploadAnswerPanel`
  - `ScoreVisibilityState`
- 新页面评审必须包含“是否遵循 design-system”检查项。

- 不覆盖旧版，保留历史版本用于回溯。
