# 接力教育智慧云平台（题库与考试系统）需求设计说明书

## 1. 项目背景与目标
为支持“广西北部湾人工智能大赛（湾赛）”及日常基础教育需求，接力教育拟建设一套集“赛前训练、赛中统考、赛后审分、日常教学”于一体的智慧云平台题库及考试系统。系统需具备高并发承载能力、严格的考试防作弊机制、灵活的题库组卷功能、多角色权限隔离机制以及完善的主观题协同评卷与复核体系。

## 2. 系统角色与核心职责
系统主要划分为以下四类核心角色（包含账号体系隔离）：
1. **管理员（平台运营/赛事方）**：负责全局配置、题库搭建、账号生成、场次与时间轴管理、考务监控、评卷规则配置及成绩审分复核。
2. **学生（训练账号）**：通过激活码获取权限，进行赛前模拟练习、日常刷题，支持答案解析查看与错题回顾。
3. **学生（考试账号）**：以身份证号为唯一标识，免激活码，仅在指定场次和时间内登录，处于严格的防作弊考试环境中。
4. **评卷/指导老师**：分为日常教学的指导老师（拥有资源访问、智能组卷权限、查看学生学情）和赛事评卷老师（负责主观题线上打分、处理复查申请、填写评语）。

## 3. 详细功能模块设计

### 3.1 管理员端 (Admin)
管理员端是平台的核心调度中心，涵盖赛务、教务与数据管理。

* **3.1.1 基础数据与账号管理**
    * **名单批量导入**：支持下载标准 Excel 模板，批量导入参赛学生/指导老师基础信息，也支持导入参赛学生后，手工配置或修改关联的指导老师。自动建立基础数据库。
    * **账号批量生成**：支持训练账号（批量生成密码表）与考试账号（身份证+统一密码）的自动化创建与激活管理。
    * **激活码管理**：生成四类激活码，支持线上购买直发与线下批量分发。追踪激活状态。
    * **设备登录限制**：单点登录（SSO）管控，多端登录强制踢出旧设备。
* **3.1.2 题库与资源中心管理**
    * **题库搭建**：按学段、知识点、题型录入试题及详细解析。
    * **计分规则配置**：客观题支持自定义分值，多选题严格执行“少选全对得 1 分，多选/错选不得分”。
    * **资源管理与版权保护**：四级目录分类管理，支持各类附件上传。所有资源仅限在线预览，防下载、防复制。
* **3.1.3 考试场次与时间轴管控（核心控制）**
    * **场次与门禁控制**：精准匹配“学段-场次-白名单”，未到时间或跨场次严格阻断。
    * **考务时间配置（新增）**：支持灵活配置【对应学段-考试场次】的起止时间、阅卷截止时间。
        * 支持快捷配置（如考后自定义N小时作为阅卷截止时间）或指定具体日期时间。
        * **考前修改**：在考试未开始之前，支持随时修改场次的起止时间和阅卷截止时间。
        * **考后延期**：考试结束后，如遇评卷进度滞后等情况，支持一键延长阅卷截止时间。
    * **全局与单人延时**：后台一键开启全场延时，或针对个别故障学生进行单人补时。
    * **考场监控大盘**：可视化展示当前在线人数、交卷人数、异常掉线人数。
* **3.1.4 赛后审分、评卷进度与数据管理**
    * **主观题评卷规则配置**：支持自定义某场次/某题型由几名评卷老师参与打分；主观题最终成绩统一按平均分计算。
    * **评卷进度监控**：后台实时查看各场次的主观题评卷进度，精准定位未完成打分的评卷老师。
    * **公布成绩时间配置（新增）**：在评卷老师完成全部考生的主观题评分后，管理员可正式设置并开启“公布成绩时间”。
    * **复查申请审批与流转**：接收学生端提交的考后成绩复查申请，支持批量通过并自动流转推送至对应的评卷老师或专家组进行人工复核。
    * **多维成绩导出**：按学段/场次筛选导出“完整版”与“脱敏简化版” Excel 成绩表。

### 3.2 学生端 - 训练账号 (Student Practice)
侧重于知识掌握与赛前热身。

* **3.2.1 首页数据看板**
    * **学情总览**：直观展示个人的累计刷题量、练习总时长、平均正确率趋势图。
    * **快捷入口**：提供“继续上次练习”、“进入错题本”、“最新模拟卷”的快捷点击通道。
* **3.2.2 模拟训练与错题本**
    * 激活后解锁对应题库，不限次作答，支持单题与全卷模式。提交后即时展示得分与图文解析。
    * 答错的客观题自动进入专属错题本，支持按知识点分类回顾。

### 3.3 学生端 - 考试账号 (Student Exam)
侧重于公平、稳定、防作弊的沉浸式竞技体验。

* **3.3.1 极简登录与身份核验**
    * 身份证+密码登录，自动跳转对应考场。首次登录强制核对个人信息。
* **3.3.2 稳定答题与进度导航**
    * **答题矩阵导航（新增）**：答题界面左侧按题型分布展示每道题的题号矩阵，实时区分“未答”和“已答”状态。支持学生自由点击题号，快速切换至任何题目。
    * **进度可视**：页面显著位置实时展示总体答题进度（如：已答 45 题 / 总计 50 题）。
    * **实时自动保存**：每操作一题即刻云端同步，断网重新登录后 100% 恢复答题进度。
    * **基础防作弊**：限制切屏次数，禁止右键复制，页面增加半透明实名水印。
* **3.3.3 提交流程与隐式算分**
    * **交卷拦截提示（新增）**：前置校验主观题附件是否上传。点击“交卷”时，系统弹出阻断提示框，明确告知“未答数量 / 已答数量”，学生可选“返回试卷”继续答题，或“确认交卷”。
    * **客观题即时计算（API静默处理）**：交卷成功后，后台 API 需立即对客观题进行自动判卷并得出得分，但**该分数对学生绝对不可见**。待评卷老师完成主观题打分后，系统自动将其与客观题得分相加，得出最终总成绩。
* **3.3.4 成绩发布与申诉闭环**
    * **成绩门禁（新增）**：在到达管理员设定的“公布成绩时间”之前，成绩查询入口封闭，页面仅展示“预计公布成绩时间：XXXX-XX-XX XX:XX”。
    * **成绩查询与发起复查**：到达公布成绩时间后，学生方可查阅总分、客观题成绩、主观题得分及裁判评分表扫描件。对成绩有异议可点击“申请复查”提交理由。
    * **复查处理后可见内容**：管理员及评卷老师复查完毕后，学生可查看复查结论（维持原判/已更正）、最新成绩明细及评卷老师给出的复核理由与评语。

### 3.4 评卷老师/指导老师端 (Teacher & Reviewer)
服务于日常教研和赛后公正评分。

* **3.4.1 首页工作看板**
    * **评卷老师看板**：展示“待评阅试卷数”、“已评阅数”、距离阅卷截止时间的倒计时进度条。设立专属的“待处理复查申请”高亮提醒模块。
    * **指导老师看板**：展示所带参赛学生的训练活跃度排名、模拟考平均分趋势、最新通知及快捷组卷入口。
* **3.4.2 赛后评卷与实时统分**
    * **在线独立打分**：在工作台查阅考生的主观题附件，在线录入分数。
    * **智能统分引擎**：当考生的主观题被所有分配的老师打分完毕后，系统立即按平均分规则得出主观题最终成绩并自动与此前的客观题得分合成总分。
    * **线下凭证留存**：支持上传纸质评分表电子扫描件作为补充归档。
* **3.4.3 成绩复核与重判工作台（闭环处理）**
    * **复查工单处理**：进入复查专属页面，查看学生提交的“复查理由”及原卷附件。
    * **重判决策与强制留痕**：判断“维持原判”或“同意重新打分”，系统强制要求填写“复查意见/理由”，直接同步至学生端。

## 4. 关键性能指标与非功能性需求 (NFR)

* **高并发承载性能（核心重点）**：考场开考瞬间需支持 1000 - 3000 QPS；答卷提交瞬间 API 即时算分的逻辑需做异步削峰处理（防堵塞）；答题期自动保存需具备防抖与高并发写入能力。
* **数据高可用与安全性**：主观题大附件采用分片上传与断点续传；训练与考试数据严格隔离；敏感数据加密存储。
* **操作溯源机制**：详细记录所有核心操作日志（含管理员修改场次时间轴、评卷老师打分/重判修改痕迹、学生上传/交卷操作等）。

## 5. 实施计划 (Roadmap)
* 一次性完成，没有迭代计划。
