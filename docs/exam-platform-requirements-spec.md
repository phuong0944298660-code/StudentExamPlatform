# 考试培训平台详细需求设计说明书

## 1. 文档信息
- 项目名称：接力教育智慧云平台题库与考试培训系统
- 对齐依据：《20260317 接力教育智慧云平台题库需求明细单.xlsx》
- 文档版本：V1.0
- 编制日期：2026-03-25
- 技术约束：前端 `Vue`，后端 `Java`，数据库 `MySQL`，部署方式 `Docker` 容器化

## 2. 建设目标与范围
本系统用于支撑赛前练习、赛中考试、赛后评分与成绩查询闭环，覆盖账号、题库、资源、考试、评分、导出、留痕与数据留存。

本期范围包含：
- 赛前：账号与激活码、题库搭建、练习题库、资源中心、报名名单导入与信息补全
- 赛中：登录与场次控制、答题与自动保存、时间管理与个体延时
- 赛后：客观题自动评分、主观题多评卷老师在线评分、成绩计算与导出、查询与审分配合
- 平台：权限控制、审计留痕、并发与性能保障、容器化部署

## 3. 角色定义
- 平台管理员：平台全局配置与运营管理角色
- 赛事管理员：赛事组织方角色，负责赛事配置与结果审阅
- 评卷老师：仅负责主观题评卷
- 教师：使用练习题库、访问培训资源、教学辅助
- 学生：练习与考试答题、成绩查询
- 家长：查询学生成绩与关键记录（可选独立端）

## 4. 角色权限总览
| 模块 | 平台管理员 | 赛事管理员 | 评卷老师 | 教师 | 学生 | 家长 |
|---|---|---|---|---|---|---|
| 账号管理 | 全量 | 查看部分 | 无 | 无 | 无 | 无 |
| 激活码管理 | 全量 | 查看部分 | 无 | 使用 | 使用 | 无 |
| 报名名单导入/信息补全 | 全量 | 发起/确认 | 无 | 无 | 补全本人 | 无 |
| 题库管理 | 全量 | 审核 | 无 | 练习使用/扩展编辑 | 练习与考试使用 | 无 |
| 培训资源中心 | 全量 | 审核 | 无 | 可访问 | 不可访问 | 无 |
| 场次与时间管理 | 全量 | 审核 | 无 | 无 | 被动使用 | 无 |
| 主观题评卷 | 分配与复核 | 查看 | 执行 | 无 | 无 | 无 |
| 成绩导出与查询 | 全量 | 导出/查看 | 查看本人任务成绩 | 查看授课学生（可选） | 查看本人 | 查看监护学生 |
| 日志审计 | 全量 | 查看 | 查看本人 | 无 | 无 | 无 |

约束说明：
- 学生激活码：仅可解锁题库模块
- 教师激活码：可解锁题库模块 + 培训资源模块
- 激活码必须可配置生效时限范围（生效开始时间、失效结束时间）

## 5. 按角色的详细功能模块需求

## 5.1 平台管理员

### 5.1.1 账号管理
- 批量生成赛前练习账号，支持一次生成约 `300-600` 个账号并导出账号密码表
- 批量生成赛中考试账号，默认账号规则为学生身份证号，支持统一初始密码策略
- 账号按学段隔离（小学组、初中组），禁止跨学段登录使用
- 单账号单会话登录，后登录设备挤出先登录设备
- 支持登录异常排查（账号不存在、密码错误、锁定、未激活、已过期）

### 5.1.2 激活码管理
- 激活码类型：小学教师、小学学生、初中教师、初中学生
- 权限映射：
  - 教师激活码：解锁对应学段题库 + 对应学段培训资源
  - 学生激活码：仅解锁对应学段题库
- 支持线上自动分配（购买后自动发码）与线下批量生成发放
- 激活码生效时限配置：
  - 可设置生效开始时间
  - 可设置失效结束时间
  - 支持查看激活码状态（未生效、有效中、已过期、已冻结、已使用）
- 激活记录留痕：激活人、激活时间、设备标识、来源渠道

### 5.1.3 报名名单导入与信息补全
- 提供报名名单 `Excel` 模板下载
- 支持 `Excel` 批量导入基础信息：地区、项目编号、项目名称、组别、学生姓名、身份证号、学校、指导老师姓名、指导老师单位、联系方式
- 导入校验：
  - 身份证号唯一性
  - 必填字段完整性
  - 学段与组别合法性
- 对异常数据给出错误行与原因，支持修复后二次导入
- 提供学生信息补全入口，仅允许补全可编辑字段并保留修改日志

### 5.1.4 题库搭建与录入
- 支持按赛事要求搭建多套题库（如 10 套），并区分小学组/初中组
- 题型支持：单选题、多选题、判断题、主观题
- 支持两种录入方式并存：
  - 在线手工录入题目
  - `Excel` 模板批量导入题目
- 客观题支持分值和评分规则配置（含多选题少选得分规则）
- 主观题支持参考答案、评分标准、关键词标注
- 题目支持按知识点、题型、难度标签管理（为后续组卷能力预留）

### 5.1.5 题库匹配与场次配置
- 按学段-场次-学生名单配置题库分配关系
- 支持场次调整、合并与重排，并同步更新题库匹配关系
- 可配置场次开放时间、关闭时间、紧急开关

### 5.1.6 资源中心管理
- 分类层级支持：
  - 一级：人工智能模块下“竞赛资源 2026”
  - 二级：小学组、初中组
  - 三级：按题库套次分文件夹
  - 四级：试题、讲解视频、PPT课件、程序代码包
- 支持上传格式：`ppt/pptx`、`doc/docx`、视频、`zip/rar`
- 资源仅支持在线预览，不提供下载入口
- 按激活码权限控制访问范围

### 5.1.7 考试时间管理
- 按学段/场次设置基础答题时长
- 支持全场统一延长时长（开关式）
- 支持单个考生延长时长（指定学生、延长分钟数、生效时点）
- 实时倒计时展示，到时自动交卷或锁卷
- 延时操作需记录审计日志（操作人、时间、原因、目标对象）

### 5.1.8 考试过程与提交控制
- 学生登录后自动进入对应场次，不允许跨场次提前进入
- 答题记录自动保存（按操作触发，至少每题作答后保存）
- 学生支持在各题型页面间自由切换作答顺序
- 主观题答题方式为富文本编辑，不采用附件上传
- 交卷前校验主观题是否填写完成（按配置规则）
- 提交二次确认弹窗
- 记录精确提交时间（至少精确到秒）并用于同分排名

### 5.1.9 评分管理
- 客观题提交后自动评分
- 主观题评分配置：
  - 配置每题或每场次评卷老师人数（如 3 人、5 人）
  - 评卷老师独立登录系统评分
  - 可配置主观题合成规则：平均值、中位数
- 允许管理员在授权场景下进行分数修订，必须填写修订原因并留痕
- 明确不支持：批量上传评分表压缩包（本期不做）

### 5.1.10 成绩导出、查询与审分
- 成绩导出字段支持：序号、地区、项目编号、项目名称、组别、每人一组、学生姓名、身份证号、学校、指导老师信息、客观题分项、主观题分数、总分、提交时间
- 支持按学段、场次、时间区间筛选导出
- 支持完整版和简化版导出（敏感字段脱敏或删除）
- 同分排序规则支持“提交时间早者优先”
- 成绩查询端口可配置开放时间范围
- 审分支持查看主观题作答内容、评卷记录、提交时间、日志凭证

### 5.1.11 数据留存与优化反馈
- 题库与资源支持长期留存并复用
- 成绩、评分、提交、登录、配置变更日志按规定周期留存
- 提供赛后问题反馈入口和跟踪处理状态

## 5.2 赛事管理员
- 维护赛事基础信息、场次安排、开放时间窗口
- 提交题库清单与资源命名规则，确认题库匹配策略
- 审核成绩导出结果、配置查询开放窗口
- 配合审分复核，查看评分与日志凭证

## 5.3 评卷老师
- 账号登录评卷端，仅可访问分配给自己的主观题任务
- 按题目评分标准进行打分与评语填写
- 支持暂存、提交、查看历史评分记录
- 评卷超时提醒与任务进度可视化
- 不可查看无权限学生隐私信息

## 5.4 教师

### 5.4.1 练习题库
- 通过教师激活码解锁对应学段题库
- 支持多次练习与多次提交
- 支持查看练习结果、答案解析与错题回顾

### 5.4.2 培训资源
- 教师激活码可解锁并访问培训资源中心
- 支持在线预览课件、文档、视频、代码包说明

### 5.4.3 后续扩展（来自需求单扩展项）
- 可支持自定义编辑题目、创建个人题库
- 可支持按知识点与题型组卷训练

## 5.5 学生

### 5.5.1 练习题库
- 通过学生激活码解锁对应学段题库
- 支持同一练习多次提交
- 可查看练习成绩与解析

### 5.5.2 正式考试
- 以身份证号+密码登录并自动进入对应场次
- 客观题按规则作答
- 主观题在系统内富文本作答
- 支持自动保存与异常恢复
- 支持查看剩余时间并按流程提交

### 5.5.3 资源权限说明
- 学生激活码不解锁培训资源
- 学生不可访问培训资源中心

### 5.5.4 成绩查询
- 仅查询本人成绩、提交时间、主观题作答记录及评分结果摘要

## 5.6 家长（可选独立端）
- 与学生绑定后查询对应学生成绩与关键记录
- 无编辑与操作权限，仅可读

## 6. 关键业务规则
- 学段隔离：小学组与初中组账号、题库、激活码权限严格隔离
- 账号安全：禁止多端同时在线
- 激活码时效：未到生效时间不可用，到期后自动失效
- 主观题评分：按配置评卷人数执行，按配置聚合规则计算主观题最终分
- 成绩可追溯：任一分值改动必须有操作人、时间、原因
- 排名规则：总分优先，同分按提交时间升序

## 7. 非功能需求

## 7.1 并发与性能（单校参考）
参考一个中大型初高中在统一考试窗口的峰值能力目标：
- 同时在线用户：`800-1500`
- 同时答题人数：`500-1000`
- 开考前5分钟登录洪峰：`300-600` 次登录请求/分钟

性能目标：
- 登录接口 `P95 < 2s`
- 题目加载 `P95 < 1.5s`
- 自动保存 `P95 < 800ms`，成功率 `>= 99.9%`
- 提交试卷 `P95 < 2s`，成功率 `>= 99.95%`
- 评卷提交 `P95 < 2s`

## 7.2 稳定性与可靠性
- 关键时段系统可用性：`>= 99.9%`
- 作答与评分数据防丢失，关键写操作需事务与幂等保障
- 服务异常可快速恢复，目标 `RTO <= 10分钟`

## 7.3 安全与合规
- 密码加密存储，敏感字段脱敏展示
- 接口鉴权与角色权限校验
- 全链路操作日志留存与审计
- 导出文件权限控制与水印标识（可选）

## 8. 技术架构设计

## 8.1 前端（Vue）
- 技术栈：`Vue 3 + TypeScript + Vue Router + Pinia + Element Plus`
- 端划分：
  - 管理后台端（管理员/赛事管理员）
  - 评卷端（评卷老师）
  - 用户端（教师/学生/家长）
- 核心能力：权限路由、动态菜单、考试倒计时、自动保存、富文本编辑器、导入导出

## 8.2 后端（Java）
- 技术栈：`Java 17 + Spring Boot + Spring Security + MyBatis/JPA`
- 核心服务：
  - 用户与权限服务
  - 激活码服务
  - 题库与考试服务
  - 评分服务
  - 成绩与导出服务
  - 日志审计服务
- 关键机制：幂等提交、防重复交卷、异步导出、缓存加速、限流与降级

## 8.3 数据库（MySQL）
核心数据表建议：
- `user` 用户表
- `role` / `user_role` 角色权限表
- `activation_code` 激活码表
- `activation_record` 激活记录表
- `enrollment` 报名信息表
- `question_bank` 题库表
- `question` 题目表
- `exam_session` 场次表
- `exam_paper` 试卷表
- `exam_answer` 作答记录表
- `subjective_score` 主观题分值表（按评卷老师多条）
- `score_policy` 评分策略表（评卷人数、聚合算法）
- `exam_score` 汇总成绩表
- `resource_file` 资源文件表
- `operation_log` 操作日志表

## 8.4 Docker 容器化部署
建议容器编排：
- `web`：前端静态资源 + `Nginx`
- `api`：Java 后端服务
- `mysql`：MySQL 8.x
- `redis`：缓存与会话（建议）
- `minio`：对象存储（可选，用于资源与导出文件）

部署建议：
- 使用 `docker compose` 统一编排
- 按环境拆分配置：`dev/test/prod`
- 数据库与对象存储使用独立数据卷持久化

## 9. 分期建议

一期（必须上线）：
- 账号与激活码、时效配置、报名导入、题库录入（手工+Excel）、赛中答题、主观题富文本、评分老师在线评分、平均值/中位数计算、成绩导出查询、单人延时、日志审计

二期（扩展能力）：
- 教师高级组卷、个人题库沉淀、更多评分算法（去极值平均等）、智能辅助评阅

## 10. 验收要点
- 激活码权限与时效规则准确生效
- 学生主观题为富文本，不走上传流程
- 教师/学生练习题库均支持多次提交
- 主观题支持按配置评卷人数执行并按算法自动汇总
- 支持单个考生延长时间且留痕可查
- 支持报名名单 `Excel` 导入与学生信息补全
- 单校并发目标下关键链路性能达标
