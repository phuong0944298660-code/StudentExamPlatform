# 接力教育智慧云平台 - 技术栈选型清单

基于平台需支撑考场开考瞬间的高并发（1000 - 3000 QPS）、答题实时防抖自动保存、大文件分片上传等核心业务场景，本项目采用前后端分离架构，并进行容器化部署。

## 1. 前端技术栈 (Frontend)
全面采用 Vue 3 生态，保障页面渲染性能与复杂考场交互的流畅度。

* **核心框架**：**Vue 3** (采用 Composition API 组合式语法，提供更好的逻辑复用)
* **构建工具**：**Vite** (提供极速的冷启动和热更新，提升开发效率)
* **状态管理**：**Pinia** (替代 Vuex，更轻量且完美支持 TypeScript，用于管理考生登录状态、全局时间轴)
* **路由管理**：**Vue Router 4** (管理平台多角色独立工作台权限控制及页面跳转)
* **UI 组件库**：**Element Plus** 或 **Ant Design Vue** (适配 Vue 3 的成熟 PC 端组件库，用于快速搭建后台管理与教师工作台界面)
* **网络请求**：**Axios** (封装统一的请求拦截、鉴权机制及断网重连逻辑)
* **CSS 框架**：**Tailwind CSS** (可选，用于原子化快速编写定制化考场样式)

## 2. 后端技术栈 (Backend)
采用主流的 Java 架构，保障系统的健壮性与高并发处理能力。

* **开发语言**：**Java 21** (最新长期支持版 LTS，具备虚拟线程 Virtual Threads 特性，天然契合高并发吞吐场景)
* **核心框架**：**Spring Boot 3.x** (最新企业级脚手架，内置高性能 Web 容器)
* **安全与鉴权**：**Spring Security + JWT** (结合 Redis 实现多端单点登录 SSO、Token 续签与顶号踢出机制)
* **ORM 框架**：**MyBatis-Plus** (极大简化单表 CRUD 操作，配合自定义 SQL 处理复杂的成绩统分逻辑)
* **接口文档**：**Knife4j / Swagger 3** (规范化 API 接口管理，方便前后端对接)

## 3. 数据库与中间件 (Database & Middleware)
针对考试系统的“防丢失”与“削峰填谷”需求引入核心中间件。

* **关系型数据库**：**MySQL 8.x** (支持更优的 JSON 字段处理与窗口函数，用于存储核心业务数据如账号、题库、成绩等)
* **内存缓存数据库**：**Redis 7.x** (核心必备：处理考场高频时间戳、字典数据缓存、单点登录 Session 共享、以及答题卡防抖提交的临时存储)
* **消息队列**：**RabbitMQ** 或 **Kafka** (用于交卷瞬间的“异步削峰”：客观题交卷后立即投入队列异步算分，避免开考和交卷瞬间数据库崩溃)
* **对象存储**：**MinIO** 或 **阿里云 OSS / 腾讯云 COS** (用于存储学生主观题大附件、视频解析、教师评分表扫描件，支持分片上传与断点续传)

## 4. 部署与运维架构 (Deployment & DevOps)
全面容器化，保障测试环境与生产环境高度一致，便于后续赛事扩容。

* **容器化引擎**：**Docker Server** (将前后端应用及部分中间件打包为镜像)
* **容器编排**：**Docker Compose** (用于单机或小型集群的快速一键编排启动；若后期规模扩大，可平滑迁移至 K8s)
* **反向代理与网关**：**Nginx** (处理 SSL 证书、动静分离、跨域配置，以及前端包的宿主服务)
* **持续集成/持续部署 (CI/CD)**：**Jenkins** 或 **GitLab CI** (自动化拉取代码、打包镜像并推送至服务器部署)
