# 考试培训平台详细需求设计说明书

## 1. 文档信息

- 项目名称：接力教育智慧云平台题库与考试培训系统
- 对齐依据：《20260317 接力教育智慧云平台题库需求明细单.xlsx》
- 文档版本：V1.2
- 编制日期：2026-03-26
- 技术约束：前端 `Vue`，后端 `Java`，数据库 `MySQL`，部署方式 `Docker` 容器化

## 2. 建设目标与范围

本系统用于支撑赛前练习、赛中考试、赛后评卷与成绩查询闭环，覆盖账号、题库、资源、考试、评卷、导出、留痕与数据留存。

范围包含：

- 赛前：账号与激活码、练习账号价格与生效周期配置、题库搭建、资源中心、报名名单导入与信息补全
- 赛中：登录与场次控制、答题与自动保存、时间管理与个体延时、主观题上传作答
- 赛后：多评卷老师评分、成绩计算与导出、查询与审分配合
- 平台：权限控制、审计留痕、并发与性能保障、容器化部署

边界说明：

- 本系统不与收费能力打通，不包含支付、订单、退款等功能
- 练习账号支持配置价格和有效周期，仅用于账号状态与运营看板展示

## 3. 角色定义

- 平台管理员：平台全局配置与运营管理角色
- 赛事管理员：赛事组织方角色，负责赛事配置与结果审阅
- 评卷老师：负责分配到本人任务的评分操作
- 教师：使用练习题库、访问培训资源、教学辅助
- 学生：练习与考试答题、成绩查询
- 家长：查询学生成绩与关键记录（可选独立端）

约束说明：

- 学生激活码：仅可解锁题库模块
- 教师激活码：可解锁题库模块 + 培训资源模块
- 激活码必须可配置生效时限范围（生效开始时间、失效结束时间）
- 练习账号与考试账号相互独立，进入系统后只展示对应模块，不允许练习与考试模块同屏同时出现

## 5. 按角色的详细功能模块需求

## 5.1 平台管理员

### 5.1.1 账号管理

- 批量生成赛前练习账号，支持一次生成约 `300-600` 个账号并导出账号密码表
- 批量生成赛中考试账号，默认账号规则为学生身份证号
- 练习账号与考试账号相互独立，不可互替登录
- 登录账号类型和进入模块强绑定：
  - 练习账号登录后仅进入练习模块
  - 考试账号登录后仅进入考试模块
- 默认登录机制：
  - 练习账号可采用学生姓名拼音
  - 考试账号为身份证号
  - 默认密码为身份证后 8 位
- 单账号单会话登录，后登录设备挤出先登录设备
- 支持登录异常排查（账号不存在、密码错误、锁定、未激活、已过期）

### 5.1.2 练习账号价格与生效周期管理

- 支持统一配置练习账号价格，用于首页看板展示
- 支持配置练习账号生效周期：
  - 快捷选项配置（如 30 天、90 天、180 天、365 天）
  - 自定义起止时间配置
- 到期后练习账号自动失效，但账号不注销
- 失效账号支持重新激活并重新配置生效周期
- 未激活练习账号禁止进入练习题库
- 本系统不与收费功能打通，不包含“支付完成自动开通”流程

### 5.1.3 激活码管理

- 激活码类型：小学教师、小学学生、初中教师、初中学生
- 权限映射：
  - 教师激活码：解锁对应学段题库 + 对应学段培训资源
  - 学生激活码：仅解锁对应学段题库
- 支持线上自动分配与线下批量生成发放
- 激活码生效时限配置：
  - 可设置生效开始时间
  - 可设置失效结束时间
  - 支持查看激活码状态（未生效、有效中、已过期、已冻结、已使用）
- 激活记录留痕：激活人、激活时间、设备标识、来源渠道

### 5.1.4 报名名单导入与信息补全

- 提供报名名单 `Excel` 模板下载
- 支持 `Excel` 批量导入基础信息：地区、项目编号、项目名称、组别、学生姓名、身份证号、学校、指导老师姓名、指导老师单位、联系方式
- 导入校验：
  - 身份证号唯一性
  - 必填字段完整性
  - 学段与组别合法性
- 对异常数据给出错误行与原因，支持修复后二次导入
- 提供学生信息补全入口，仅允许补全可编辑字段并保留修改日志

### 5.1.5 题库搭建与录入

- 支持按赛事要求搭建多套题库（如 10 套），并区分小学组/初中组
- 题型支持：单选题、多选题、判断题、主观题
- 支持两种录入方式并存：
  - 在线手工录入题目
  - `Excel` 模板批量导入题目
- 客观题支持分值和评分规则配置（含多选题少选得分规则）
- 主观题支持参考答案、评分标准、关键词标注
- 题目支持按知识点、题型、难度标签管理
- 同步实现扩展能力：自主组卷、编辑题库、保存个人题库、下载本地化修改

### 5.1.6 场次与时间管理

- 按学段-场次-学生名单配置题库分配关系
- 支持场次调整、合并与重排，并同步更新题库匹配关系
- 可配置场次开放时间、关闭时间、紧急开关
- 平台管理员与赛事管理员均可查看场次实时开放状态
- 平台管理员与赛事管理员均可执行场次开/关操作
- 按学段/场次设置基础答题时长
- 支持全场统一延长时长（开关式）
- 支持单个考生延长时长（指定学生、延长分钟数、生效时点）
- 实时倒计时展示，到时自动锁卷
- 延时与场次开关操作需记录审计日志（操作人、时间、原因、目标对象）

### 5.1.7 资源中心管理

- 分类层级支持：
  - 一级：人工智能模块下“竞赛资源 2026”
  - 二级：小学组、初中组
  - 三级：按题库套次分文件夹
  - 四级：试题、讲解视频、PPT课件、程序代码包
- 支持上传格式：`ppt/pptx`、`doc/docx`、视频、`zip/rar`
- 资源仅支持在线预览，不提供下载入口
- 视频预览能力：
  - 支持倍速播放
  - 支持键盘左右键快进/快退 5 秒
  - 支持普通窗口和全屏播放
- 按激活码权限控制访问范围

### 5.1.8 考试过程与提交控制

- 学生登录后自动进入对应场次，不允许跨场次提前进入
- 考试态无答案解析，仅支持答题
- 答题记录实时自动保存（按操作触发，至少每题作答后保存）
- 支持前后跳转试题
- 左侧答题卡列表展示已答题目和未答题目状态
- 主观题答题方式为附件上传：
  - 支持上传图片、文档、压缩包
  - 支持预览上传内容
  - 支持重新上传
  - 完成上传视为该题已填写
  - 上传记录与状态需实时保存
- 提交二次确认弹窗
- 记录精确提交时间（至少精确到秒）并用于同分排名

### 5.1.9 评卷与成绩同步管理

- 同一份试卷配置 3 名评卷教师参与评分
- 评卷教师全部提交后，系统立即通过接口更新成绩表
- 支持评分聚合规则配置：平均值、中位数
- 评卷状态需可追踪：未评、评卷中、已评
- 允许管理员在授权场景下进行分数修订，必须填写修订原因并留痕
- 明确不支持：批量上传评分表压缩包

### 5.1.10 成绩导出、查询与审分

- 成绩导出字段支持：序号、地区、项目编号、项目名称、组别、每人一组、学生姓名、身份证号、学校、指导老师信息、客观题总分、主观题总分、总分、提交时间
- 支持按学段、场次、时间区间筛选导出
- 支持完整版和简化版导出（敏感字段脱敏或删除）
- 简化版成绩单仅展示总分和各大题型总得分，不展示每道题目得分
- 同分排序规则支持“提交时间早者优先”
- 成绩查询端口可配置开放时间范围
- 审分支持查看主观题上传内容、评卷记录、提交时间、日志凭证

### 5.1.11 数据留存与优化反馈

- 题库与资源支持长期留存并复用
- 成绩、评分、提交、登录、配置变更日志按规定周期留存
- 提供赛后问题反馈入口和跟踪处理状态

## 5.2 赛事管理员

- 维护赛事基础信息、场次安排、开放时间窗口
- 提交题库清单与资源命名规则，确认题库匹配策略
- 可查看场次实时开放状态并执行开/关操作
- 审核成绩导出结果、配置查询开放窗口
- 配合审分复核，查看评分与日志凭证

## 5.3 评卷老师

- 账号登录评卷端，仅可访问分配给自己的任务
- 按题目评分标准进行打分与评语填写
- 支持暂存、提交、查看历史评分记录
- 支持按状态筛选试卷：未评、评卷中、已评
- 评卷超时提醒与任务进度可视化
- 不可查看无权限学生隐私信息

## 5.4 教师

### 5.4.1 练习题库

- 通过教师激活码解锁对应学段题库
- 支持多次练习与多次提交
- 支持查看练习结果、答案解析与错题回顾
- 支持编辑题库、按知识点组卷、保存个人题库、下载本地化修改

### 5.4.2 培训资源

- 教师激活码可解锁并访问培训资源中心
- 支持在线预览课件、文档、视频、代码包说明

## 5.5 学生

### 5.5.1 练习题库

- 通过学生激活码解锁对应学段题库
- 支持同一练习多次提交
- 可查看练习成绩与解析
- 未激活或已过期练习账号不可进入练习题库

### 5.5.2 正式考试

- 以身份证号 + 默认密码（身份证后 8 位）登录并自动进入对应场次
- 客观题按规则作答，支持前后跳题
- 主观题通过上传图片、文档、压缩包作答，可预览与重新上传
- 上传完成视为主观题已填写
- 左侧答题卡展示已答和未答状态
- 考试态无答案解析，仅支持答题
- 支持实时自动保存与异常恢复
- 支持查看剩余时间并按流程提交

### 5.5.3 资源权限说明

- 学生激活码不解锁培训资源
- 学生不可访问培训资源中心

### 5.5.4 成绩查询

- 仅查询本人成绩、提交时间、题型总得分、评分结果摘要
- 不展示每道题目分值明细

## 5.6 家长（可选独立端）

- 与学生绑定后查询对应学生成绩与关键记录
- 无编辑与操作权限，仅可读

## 5.7 首页看板需求（V1.2新增）

### 5.7.1 通用交互规范

- 所有首页豆腐块右上角统一显示感叹号图标 `!`
- 鼠标悬停感叹号时展示该指标的口径定义
- 为兼容触屏设备，感叹号支持点击打开口径说明

### 5.7.2 平台管理员首页

- 今日总览采用单个豆腐块展示：`今日预计考试人数 / 当前考试登录人数`
- `今日预计考试人数`口径：当日所有已排考试场次应考人数总和
- `当前考试登录人数`口径：当前进行中场次内，使用考试账号成功登录的去重账户数
- 场次运行卡：待开启、进行中、已结束场次数，支持进入场次开关管理
- 评分进度卡：未评、评卷中、已评试卷数量
- 成绩同步卡：已同步数量、失败重试数量
- 告警卡：登录异常、上传失败、自动保存失败、接口超时

### 5.7.3 赛事管理员首页

- 场次看板：场次实时开放状态、下一场开始时间
- 已登录考生口径：使用考试账号登录的账户数（去重）
- 评分与出分：各场次评分完成率、成绩表更新时间
- 查询开关：成绩查询开关状态与开放窗口时间
- 审分入口：待处理质疑数量

### 5.7.4 评卷老师首页

- 我的任务总览：未评、评卷中、已评数量
- 待办列表：优先显示临近截止且未评试卷
- 规则提示：当前评分算法（平均值/中位数）与评分人数要求
- 快捷入口：继续上次评卷、按状态筛选试卷

### 5.7.5 教师首页

- 练习总览：已开通学段、可用题库数、最近练习参与情况
- 教学效果：平均分、正确率、高频错题知识点
- 资源中心：最近更新资源、热门视频
- 题库工作台：我的题库、我的组卷、最近编辑
- 激活状态：激活码有效期与到期提醒

### 5.7.6 学生首页（合并家长查看场景）

- 首页层面不再区分学生和家长角色，统一采用学生结果页展示逻辑
- 考试结果可见条件：`评分完成` 且 `成绩发布开关=开`
- 若满足可见条件：考试账号登录后可查看考试结果
- 若不满足可见条件：显示“考试结果尚未公布”状态提示
- 结果页展示：总分、各大题型总得分、提交时间、结果发布时间（如已发布）

## 6. 关键业务规则

- 学段隔离：小学组与初中组账号、题库、激活码权限严格隔离
- 账号隔离：练习账号与考试账号不可互替登录
- 模块隔离：练习账号仅显示练习模块，考试账号仅显示考试模块
- 账号安全：禁止多端同时在线
- 激活码时效：未到生效时间不可用，到期后自动失效
- 练习账号有效期：到期后失效但不注销，可重新激活并重设周期
- 评卷同步：同一试卷三名评卷教师均提交后立即更新成绩表
- 成绩可追溯：任一分值改动必须有操作人、时间、原因
- 排名规则：总分优先，同分按提交时间升序

## 7. 非功能需求

## 7.1 并发与性能（单校参考）

参考一个中大型初高中在统一考试窗口的峰值能力目标：

- 同时在线用户：`800-1500`
- 同时答题人数：`500-1000`
- 开考前 5 分钟登录洪峰：`300-600` 次登录请求/分钟

性能目标：

- 登录接口 `P95 < 2s`
- 题目加载 `P95 < 1.5s`
- 自动保存 `P95 < 800ms`，成功率 `>= 99.9%`
- 上传附件提交 `P95 < 2s`
- 评分提交 `P95 < 2s`
- 成绩表更新接口（三评卷教师提交完成后）`P95 < 2s`

## 7.2 稳定性与可靠性

- 关键时段系统可用性：`>= 99.9%`
- 作答、上传、评分数据防丢失，关键写操作需事务与幂等保障
- 服务异常可快速恢复，目标 `RTO <= 10分钟`

## 7.3 安全与合规

- 密码加密存储，敏感字段脱敏展示
- 接口鉴权与角色权限校验
- 全链路操作日志留存与审计
- 导出文件权限控制与水印标识（可选）

## 8. 技术架构设计

## 8.1 前端（Vue）

- 技术栈：`Vue 3 + TypeScript + Vue Router + Pinia + Element Plus`
- 端划分：
  - 管理后台端（平台管理员/赛事管理员）
  - 评卷端（评卷老师）
  - 用户端（教师/学生/家长）
- 核心能力：权限路由、动态菜单、考试倒计时、自动保存、文件上传与预览、视频倍速与键盘快进快退、导入导出、答题卡状态展示

## 8.2 后端（Java）

- 技术栈：`Java 17 + Spring Boot + Spring Security + MyBatis/JPA`
- 核心服务：
  - 用户与权限服务
  - 激活码服务
  - 练习账号周期与价格配置服务
  - 题库与考试服务
  - 评卷与成绩同步服务
  - 成绩与导出服务
  - 日志审计服务
- 关键机制：幂等提交、防重复交卷、异步导出、缓存加速、限流与降级

## 8.3 数据库（MySQL）

核心数据表建议：

- `user` 用户表
- `role` / `user_role` 角色权限表
- `practice_account_policy` 练习账号价格与周期策略表
- `practice_account_status` 练习账号生效状态表
- `activation_code` 激活码表
- `activation_record` 激活记录表
- `enrollment` 报名信息表
- `question_bank` 题库表
- `question` 题目表
- `exam_session` 场次表
- `exam_paper` 试卷表
- `exam_answer` 作答记录表
- `answer_upload` 主观题上传记录表
- `review_score` 评卷分值表（按评卷老师多条）
- `score_policy` 评分策略表（评卷人数、聚合算法）
- `exam_score` 汇总成绩表
- `resource_file` 资源文件表
- `operation_log` 操作日志表

## 8.4 Docker 容器化部署

建议容器编排：

- `web`：前端静态资源 + `Nginx`
- `api`：Java 后端服务
- `mysql`：MySQL 8.x
- `redis`：缓存与会话（建议）
- `minio`：对象存储（用于题目附件、主观题上传、导出文件）

部署建议：

- 使用 `docker compose` 统一编排
- 按环境拆分配置：`dev/test/prod`
- 数据库与对象存储使用独立数据卷持久化

## 9. 实施策略

- 本项目不分期，一次性完成全部能力交付
- 扩展能力（组卷、编辑题库、个人题库、本地下载）与核心能力同步实现

## 10. 验收要点

- 激活码权限与时效规则准确生效
- 练习账号支持价格配置与生效周期配置（快捷选项 + 自定义）
- 练习账号到期失效不注销，支持重新激活并重设周期
- 练习账号与考试账号不可互替登录，且模块展示互斥
- 学生考试主观题支持上传图片/文档/压缩包，支持预览和重新上传，上传状态实时保存
- 考试态无答案解析，支持前后跳题与答题卡已答/未答展示
- 视频资源支持倍速、键盘左右键前后跳 5 秒、全屏播放
- 平台管理员与赛事管理员可查看并控制场次实时开放状态
- 同一试卷三名评卷教师全部提交后，立即接口更新成绩表
- 简化版成绩单仅展示总分和各大题型总得分，不展示逐题得分
- 支持报名名单 `Excel` 导入与学生信息补全
- 单校并发目标下关键链路性能达标
- 首页豆腐块均支持感叹号悬停查看口径定义
- 平台管理员首页支持在同一豆腐块展示“今日预计考试人数 / 当前考试登录人数”
