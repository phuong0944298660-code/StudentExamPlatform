设计原则

🎯 清晰护眼

使用柔和的莫兰迪色系，避免高饱和刺眼颜色，保护学生视力

✨ 现代活力

圆润的圆角设计，适中的阴影，营造现代感而不呆板

🎯 专注聚焦

克制的动画效果，清晰的视觉层级，帮助用户专注任务

📐 统一规范

基于 4px 网格系统，保持间距、圆角、字号的一致性
